# IdeaSculptor
The main purpose of the website is mainly for unpicking thought . For example, if you have a thought but dont know how to describe it for you this website can help you arrange your thought and also simplify then for you to understand.
In the website there are like 4 steps: 
*messy dump box* - the user type whatever idea or thought the have
*guided question* - asks simple specific questions to bring out the details
*idea card summary* - once the prompts are answered, this summarises their idea in plain English
*saved vault* - this saves the formatted idea so it is not lost if they want to refer to it again
